Indítás:
1. Nyissa meg a [forraskod] mappát.
2. Indítsa el az index.html fájlt egy modern webböngészőben.
3. A regisztrációs funkció internetkapcsolatot igényel,
   mivel Google Apps Script és Google Sheets szolgáltatást használ.

A projekt főbb részei:
- HTML/CSS/JavaScript frontend
- Google Sheets-alapú adattárolás
- Google Apps Script adatfeldolgozás
- automatikus e-mailes visszaigazolás

A foglalás kizárólag az Órák munkalapon előre rögzített
óra–dátum–időpont kombinációkra hajtható végre.
